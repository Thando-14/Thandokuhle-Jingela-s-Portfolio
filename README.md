# Thandokuhle-Jingela-s-Portfolio
Welcome to the repository for my official personal portfolio website. This platform showcases my technical projects, skill set, and background in Data Science, Machine Learning, and Business Intelligence

## Key Features

* **Modern Dark-Mode UI:** Clean, responsive user interface built using custom CSS variables, flexbox, and grid layouts.
* **Interactive Navigation:** Smooth scrolling sections for quick navigation through About, Skills, Projects, Experience, and Contact details.
* **Project Showcase:** Highlights end-to-end data pipelines, predictive modeling (XGBoost, Prophet, ARIMA), and interactive Business Intelligence dashboards (Power BI, DAX).
* **Fully Responsive:** Optimized for desktop, tablet, and mobile displays.

## Built With

* **HTML5:** Semantic structural layout.
* **CSS3:** Custom styling, CSS Grid, Flexbox, media queries, and modern dark-mode color palettes.
* **Font Awesome & Google Fonts:** Clean typography (Inter) and developer iconography.
* **GitHub Pages / Vercel:** Free cloud hosting and continuous deployment.
